Установка на телефон

ORBITA — это ещё и приложение: ставится на телефон одним касанием, открывается на весь экран со своей иконкой и работает даже без интернета. Веб-версия по обычной ссылке тоже остаётся — выбирай, что удобнее.

Скачать APK-файл

Основной способ поставить приложение на Android: файл ORBITA.apk (версия 1.0, около 17 КБ). На iPhone этот файл не нужен — используйте инструкцию для Safari ниже.

Скачать ORBITA.apk
  1. Откройте скачанный файл из загрузок браузера или раздела «Файлы»
  2. Разрешите установку из этого источника, если телефон спросит (разрешение выдаётся один раз)
  3. Подтвердите установку — иконка ◍ ORBITA появится на рабочем столе

Телефон пишет «Опасное приложение»? Так Android помечает любые приложения, устанавливаемые вне официальных магазинов, — это общее предупреждение системы, а не приговор конкретному файлу. Нажмите «Подробности» (на некоторых телефонах — «Ещё») и выберите «Всё равно установить». На телефонах Honor и Huawei кнопка может называться «Разрешить» или «Установить в любом случае». Если система совсем не пускает: откройте Play Protect → Параметры, временно выключите проверку приложений, установите ORBITA и включите проверку обратно.

Android

  1. Открой сайт в браузере Chrome на телефоне
  2. Нажми меню браузера ⋮ → Установить приложение
  3. Подтверди — на рабочем столе появится иконка ◍ ORBITA

Так сайт ставится как приложение (PWA): иконка на рабочем столе и работа офлайн. Файл APK выше — альтернатива для любого Android-телефона.

iPhone (Safari)

  1. Открой сайт в браузере Safari
  2. Нажми «Поделиться» (квадрат со стрелкой внизу)
  3. Выбери «На экран “Домой”» → «Добавить»
  4. Иконка появится на телефоне, откроется на весь экран

Важно: устанавливать нужно именно через Safari — из других браузеров кнопка «Поделиться» не работает.

С телефона по QR

Наведи камеру телефона на код — откроется сайт, после чего установи его, как описано слева.

Приложение или веб-версия?

Веб-версия

Обычная ссылка в браузере. Всегда свежая версия, ничего устанавливать не нужно. Подходит для проверки с любого устройства.

Открыть сайт

Приложение

Иконка на телефоне, запуск на весь экран без адресной строки, быстрый запуск и работа офлайн. Обновляется автоматически — переустанавливать не нужно.
