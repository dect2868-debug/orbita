Установка на телефон

ORBITA — это ещё и приложение: ставится на телефон одним касанием, открывается на весь экран со своей иконкой и работает даже без интернета. Веб-версия по обычной ссылке тоже остаётся — выбирай, что удобнее.

Android

  1. Открой сайт в браузере Chrome на телефоне
  2. Нажми кнопку «Установить» ниже или меню браузера ⋮ → Установить приложение
  3. Подтверди — на рабочем столе появится иконка ◍ ORBITA

iPhone (Safari)

  1. Открой сайт в браузере Safari
  2. Нажми «Поделиться» (квадрат со стрелкой внизу)
  3. Выбери «На экран “Домой”» → «Добавить»
  4. Иконка появится на телефоне, откроется на весь экран

Важно: устанавливать нужно именно через Safari — из других браузеров кнопка «Поделиться» не работает.

С телефона по QR

Наведи камеру телефона на код — откроется сайт, после чего установи его, как описано слева.

Приложение или веб-версия?

Веб-версия

Обычная ссылка в браузере. Всегда свежая версия, ничего устанавливать не нужно. Подходит для проверки с любого устройства.

Открыть сайт

Приложение

Иконка на телефоне, запуск на весь экран без адресной строки, быстрый запуск и работа офлайн. Обновляется автоматически — переустанавливать не нужно.
