# ◍ ORBITA — сервис для космического путешественника

Демонстрационный проект федерального конкурса научных проектов: единая интеллектуальная
платформа сопровождения частного космического путешествия — от первой консультации и
подготовки до полёта, пребывания в невесомости и безопасного возвращения на Землю.

🔗 **Сайт: [https://dect2868-debug.github.io/orbita/](https://dect2868-debug.github.io/orbita/)**

## Возможности сайта

- **Главная, О сервисе, Наука, Модули, Маршрут, Эффект, Команда** — конкурсная работа по страницам
- **Регистрация и личный кабинет** — профиль путешественника, баланс (демо-бонус 500 000 ₽), билеты
- **Билеты и оплата** — каталог рейсов, покупка с баланса или картой (заглушка эквайринга, 3-D Secure: 1234)
- **Калькулятор полёта** — подбор программы по бюджету, длительности и перегрузкам с обратным отсчётом до старта
- **Интерактивный маршрут** — 7 этапов сопровождения: живой отсчёт, текущий этап, раскрытие деталей
- **Прогресс подготовки** — чек-лист из 6 этапов «по порядку», кольцо готовности и уровни допуска L0–L4
- **Новости проекта** — блог хроники разработки с фильтром по рубрикам (news.html)
- **Ежедневный бонус** — раз в сутки, серия дней подряд, от 5 000 до 10 000 ₽ на баланс
- **Достижения** — 7 значков в профиле за билеты, баланс, чек-лист и серии бонусов
- **Обратный отсчёт** — до ближайшего старта живыми секундами на главной странице
- **Голосование** — путешественники выбирают направление программы 2027 года (один аккаунт — один голос)
- **Поддержка** — чат: отвечает **YandexGPT** (бесплатный лимит в Яндекс Облаке),
  с автоматическим переключением на резервную нейросеть и базу знаний проекта
- **Админ-панель** — статистика, управление пользователями, ролями и билетами.
  Роли: **admin** (всё) и **moderator** (балансы, возвраты билетов, просмотр).
  Файл панели и все реквизиты доступа в репозиторий не публикуются.

## Защита

Многоуровневая защита аккаунтов и сервиса: аккаунты и пароли защищены
современными методами хранения и передачи, автоматические регистрации
и перебор паролей автоматически ограничиваются, служебные файлы
и панель управления в интернет не отдаются. Детальная реализация
защиты публично не описывается.

- Служебные файлы сервера, реквизиты доступа и базы данных существуют
  только локально: в репозитории их нет, история git от них чиста,
  по HTTP не отдаются.
- Сам список служебных файлов в репозиторий также не публикуется.

## Режимы работы

| Режим | Где | Данные |
|---|---|---|
| **Статичный (GitHub Pages)** | этот сайт | пока сервер проекта выключен: профиль и билеты в браузере (localStorage) |
| **Общий (с сервером)** | локально или по адресу сервера | общие данные на всех устройствах |

Сайт сам определяет режим: при загрузке проверяет доступность API проекта
и, если сервера нет, переходит в автономный режим — все функции
продолжают работать локально.
