# ◍ ORBITA — сервис для космического путешественника

Демонстрационный проект федерального конкурса научных проектов: единая интеллектуальная
платформа сопровождения частного космического путешествия — от первой консультации и
подготовки до полёта, пребывания в невесомости и безопасного возвращения на Землю.

🔗 **Сайт: [https://dect2868-debug.github.io/orbita/](https://dect2868-debug.github.io/orbita/)**

## Возможности сайта

- **Главная, О сервисе, Наука, Модули, Маршрут, Эффект, Команда** — конкурсная работа по страницам
- **Регистрация и личный кабинет** — профиль путешественника, баланс (демо-бонус 500 000 ₽), билеты
- **Билеты и оплата** — каталог рейсов, покупка с баланса или картой (заглушка эквайринга, 3-D Secure: 1234)
- **Калькулятор полёта** — подбор программы по бюджету, длительности и перегрузкам с обратным отсчётом до старта
- **Интерактивный маршрут** — 7 этапов сопровождения: живой отсчёт, текущий этап, раскрытие деталей
- **Прогресс подготовки** — чек-лист из 6 этапов «по порядку», кольцо готовности и уровни допуска L0–L4
- **Поддержка** — чат: отвечает **YandexGPT** (бесплатный лимит в Яндекс Облаке),
  с автоматическим переключением на резервную нейросеть и базу знаний проекта
- **Админ-панель** — статистика, управление пользователями, ролями и билетами.
  Роли: **admin** (всё) и **moderator** (балансы, возвраты билетов, просмотр).
  В автономной версии (GitHub Pages) staff-права активируются ключом:
  `[REMOVED]` — администратор, `[REMOVED]` — модератор.

## Режимы работы

| Режим | Где | Данные |
|---|---|---|
| **Статичный (GitHub Pages)** | этот сайт | профиль, билеты и баланс хранятся в браузере (localStorage) |
| **Полный (с сервером)** | локально | общий данные на сервере: `python server.py` → http://127.0.0.1:8080 |

Сайт сам определяет режим: при загрузке проверяет `/api/ping` и, если сервера нет,
переходит в автономный режим — все функции продолжают работать локально.

## Доступ из интернета (все браузеры и устройства)

Данные общие для всех устройств, если запустить сервер и туннель:

```bat
start_public.bat     # сервер + бесплатный туннель localtunnel
```

Адрес вида `https://xxxx-xxxx.loca.lt` появляется в отдельном окне и сохраняется
в `public_url.txt`. Первый заход показывает однократную страницу подтверждения
(кнопка Continue). Адрес меняется после перезапуска туннеля, поэтому сервер
нужно держать запущенным.

## Запуск с сервером локально

```bash
python server.py            # порт 8080, данные в ./data/data.json
```

Аккаунт администратора создаётся автоматически: `[REMOVED]` / `[REMOVED]`
(меняется через переменные окружения `ADMIN_EMAIL` / `ADMIN_PASSWORD`).

## Чат поддержки: YandexGPT

Отвечает нейросеть **YandexGPT** (Яндекс Облако, у моделей есть бесплатный
месячный лимит токенов). Нужны ID фолдера и API-ключ из cloud.yandex.ru
(сервисный аккаунт → «Ключи»). Ключ задаётся одним из способов:

```bash
# способ 1 — переменные окружения
set YANDEXGPT_FOLDER_ID=b1g...
set YANDEXGPT_API_KEY=AQVN...
python server.py

# способ 2 — файл рядом с server.py (в репозиторий не попадает),
# первая строка — ID фолдера, вторая — ключ (или "folder:ключ" в одну строку)
python server.py
```

Без ключа чат работает как раньше: резервный канал pollinations.ai,
а при его недоступности — база знаний проекта (FAQ).

> ⚠️ `test_api.py` — smoke-тест, он **удаляет** `data/data.json` перед прогоном
> (запускайте с флагом `--keep`, чтобы сохранить данные).

## Уведомления владельцу на e-mail

Каждое сообщение в чат поддержки продублировано письмом владельцу
(фоном, чат не замедляется; дубликаты не чаще раза в 2 минуты).
**Ответить посетителю можно письмом**: просто ответьте на уведомление
(кнопка «Ответить») — сервер раз в 30 секунд забирает ответ из почтового
ящика и показывает его посетителю в чате следующим сообщением.
Настройка — файл `email_notify.txt` рядом с `server.py` (5 строк: SMTP-сервер,
порт, логин, пароль приложения, e-mail получателя) или переменные окружения
`ORBITA_SMTP_HOST` / `ORBITA_SMTP_PORT` / `ORBITA_SMTP_LOGIN` /
`ORBITA_SMTP_PASSWORD` / `ORBITA_NOTIFY_TO`.

Пароль приложения для Gmail: myaccount.google.com/apppasswords (нужна
двухэтапная проверка). Пока пароль не вставлен, уведомления молча
выключены и чат работает как обычно. SMTP Яндекса провайдер блокирует,
поэтому используется Gmail.

> Уведомления отправляет серверная версия сайта (запуск на компьютере
> или через публичную ссылку). В автономной версии на GitHub Pages сервера
> нет — письма оттуда не уходят.
