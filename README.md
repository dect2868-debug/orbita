# ◍ ORBITA — сервис для космического путешественника

Демонстрационный проект федерального конкурса научных проектов: единая интеллектуальная
платформа сопровождения частного космического путешествия — от первой консультации и
подготовки до полёта, пребывания в невесомости и безопасного возвращения на Землю.

🔗 **Сайт: [https://dect2868-debug.github.io/orbita/](https://dect2868-debug.github.io/orbita/)**

## Возможности сайта

- **Главная, О сервисе, Наука, Модули, Маршрут, Эффект, Команда** — конкурсная работа по страницам
- **Регистрация и личный кабинет** — профиль путешественника, баланс (демо-бонус 500 000 ₽), билеты
- **Билеты и оплата** — каталог рейсов, покупка с баланса или картой (заглушка эквайринга, 3-D Secure: 1234)
- **Калькулятор полёта** — подбор программы по бюджету, длительности и перегрузкам с обратным отсчётом до старта
- **Интерактивный маршрут** — 7 этапов сопровождения: живой отсчёт, текущий этап, раскрытие деталей
- **Прогресс подготовки** — чек-лист из 6 этапов «по порядку», кольцо готовности и уровни допуска L0–L4
- **Поддержка** — чат: отвечает **YandexGPT** (бесплатный лимит в Яндекс Облаке),
  с автоматическим переключением на резервную нейросеть и базу знаний проекта
- **Админ-панель** — статистика, управление пользователями, ролями и билетами.
  Роли: **admin** (всё) и **moderator** (балансы, возвраты билетов, просмотр).
  Панель и все реквизиты доступа к ней существуют только локально
  и в репозиторий не публикуются.

## Режимы работы

| Режим | Где | Данные |
|---|---|---|
| **Статичный (GitHub Pages)** | этот сайт | пока туннель выключен: профиль и билеты в браузере (localStorage) |
| **Общий (с сервером)** | локально или через туннель | общие данные на сервере: `python server.py` → http://127.0.0.1:8080 |

Сайт сам определяет режим: при загрузке пробует `/api/ping` (на GitHub Pages —
адрес из `layout.js`) и, если сервера нет, переходит в автономный режим —
все функции продолжают работать локально.

## Доступ из интернета и общий режим для GitHub Pages

Один двойной клик запускает всё сразу:

```bat
start_orbita.bat     # сервер + туннель + адрес публикуется на Pages
```

Скрипт поднимает `server.py`, открывает туннель — сначала localtunnel
(`https://*.loca.lt`), при его недоступности cloudflared — записывает адрес
в `public_url.txt` и `layout.js` и отправляет его в репозиторий —
GitHub Pages обновляется примерно за минуту. После этого сайт на
[GitHub Pages](https://dect2868-debug.github.io/orbita/) работает с вашим
сервером: общие аккаунты и билеты на всех устройствах, вход по логину,
а Excel-база `database/accounts.xlsx` пополняется даже из интернета.

Пока скрипт и сервер запущен — общий режим. Закрыли — сайт сам вернётся
в автономный режим (localStorage), ничего не ломается. Адрес туннеля
меняется при каждом запуске, поэтому его публикация встроена в скрипт.

> При открытии адреса туннеля напрямую в браузере первый заход покажет
> страницу подтверждения localtunnel (пароль — имя туннеля из адреса).
> На работу сайта это не влияет: GitHub Pages обращается к API без этих
> подтверждений.

## Запуск с сервером локально

```bash
python server.py            # порт 8080, данные в ./data/data.json
```

Панель администратора и все реквизиты доступа к ней существуют только
локально на вашем компьютере и в репозиторий не публикуются.

## Чат поддержки: YandexGPT

Отвечает нейросеть **YandexGPT** (Яндекс Облако, у моделей есть бесплатный
месячный лимит токенов). Нужны ID фолдера и API-ключ из cloud.yandex.ru
(сервисный аккаунт → «Ключи»). Ключ задаётся одним из способов:

```bash
# способ 1 — переменные окружения
set YANDEXGPT_FOLDER_ID=b1g...
set YANDEXGPT_API_KEY=AQVN...
python server.py

# способ 2 — файл рядом с server.py (в репозиторий не попадает),
# первая строка — ID фолдера, вторая — ключ (или "folder:ключ" в одну строку)
python server.py
```

Без ключа чат работает как раньше: резервный канал pollinations.ai,
а при его недоступности — база знаний проекта (FAQ).

> ⚠️ `test_api.py` — smoke-тест, он **удаляет** `data/data.json` перед прогоном
> (запускайте с флагом `--keep`, чтобы сохранить данные).

## Уведомления владельцу на e-mail

Каждое сообщение в чат поддержки продублировано письмом владельцу
(фоном, чат не замедляется; дубликаты не чаще раза в 2 минуты).
**Ответить посетителю можно письмом**: просто ответьте на уведомление
(кнопка «Ответить») — сервер раз в 30 секунд забирает ответ из почтового
ящика и показывает его посетителю в чате следующим сообщением.
Настройка — файл `email_notify.txt` рядом с `server.py` (5 строк: SMTP-сервер,
порт, логин, пароль приложения, e-mail получателя) или переменные окружения
`ORBITA_SMTP_HOST` / `ORBITA_SMTP_PORT` / `ORBITA_SMTP_LOGIN` /
`ORBITA_SMTP_PASSWORD` / `ORBITA_NOTIFY_TO`.

Пароль приложения для Gmail: myaccount.google.com/apppasswords (нужна
двухэтапная проверка). Пока пароль не вставлен, уведомления молча
выключены и чат работает как обычно. SMTP Яндекса провайдер блокирует,
поэтому используется Gmail.

> Уведомления отправляет серверная версия сайта (запуск на компьютере
> или через публичную ссылку). В автономной версии на GitHub Pages сервера
> нет — письма оттуда не уходят.

```
tickets.html, econ.html, team.html, support.html, profile.html, login.html,
register.html, payment.html                  — страницы сайта
admin.html                                   — панель администратора (только
                                              локально, на Pages не публикуется)
style.css                                  — стили проекта
auth.js, layout.js, script.js              — авторизация, шапка/подвал, анимации
assets/                                    — фоновые видео и постеры к ним:
    hero-loop.mp4   — космос за заголовком главной (планета, орбита, метеоры);
    launch.mp4      — «Разгон и выход на орбиту» (route.html);
    orbit.mp4       — «Вид на Землю с борта» (tickets.html);
    nebula.mp4      — «Глубокий космос» (about.html);
    prep.mp4        — «Центрифуга» (schedule.html)
make_hero_video.py                        — генератор видео главной страницы
make_page_videos.py                       — генератор видео внутренних страниц
    запуск: python make_hero_video.py / python make_page_videos.py
    (нужны пакеты numpy, pillow, imageio-ffmpeg)
database/                                  — Excel-база аккаунтов accounts.xlsx
                                             (листы: Сводка, Аккаунты, Билеты,
                                             Операции; пишется при каждом
                                             сохранении сервера, по HTTP не
                                             отдаётся, в git не попадает)
layout.js (последние строки)              — адрес API сервера для GitHub Pages
                                             (заполняет start_orbita.ps1)
start_orbita.bat / start_orbita.ps1        — сервер + туннель + публикация
                                             адреса на Pages
server.py                                  — API-сервер (стандартная библиотека
                                             Python; только локально, в git не
                                             публикуется вместе с admin.html)
admin_key.txt                              — пароль администратора (только
                                             локально, в git не попадает)
```

*Проект носит демонстрационный характер: платежи выполняются заглушкой эквайринга.*
